# Expressifying

This repository supports the ongoing project:

**"Testing Diversifying Selection on Gene Expression Levels Across Animal Species"**

## Project Overview

This project investigates whether gene expression levels evolve under diversifying selection by comparing within- and between-species variation. It applies the method described in:

> Latrille T, Bastian M, Gaboriau T, Salamin N. (2024). Detecting diversifying selection for a trait from within and between-species genotypes and phenotypes. *Journal of Evolutionary Biology*, 37(12):1538–1550. [https://doi.org/10.1093/jeb/voae084](https://doi.org/10.1093/jeb/voae084)

### Key Components

- **Gene Expression Data**: Curated RNA-seq expression data from the [Bgee database](https://www.bgee.org/), focusing on healthy wild-type samples across multiple animal species.
- **Orthology Mapping**: One-to-one orthologous genes identified using the [OMA Browser](https://omabrowser.org/oma/home/), ensuring accurate cross-species comparisons.
